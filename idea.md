# Rally — Mobile Social Gaming Platform

## Overview

Rally is a mobile social gaming platform for **iOS and Android** that allows users to discover, play, and enjoy a collection of small 2D and 3D games within a single application.

Inspired by Roblox, Rally provides a centralized gaming ecosystem where users can browse games, join multiplayer servers, create private lobbies, invite friends, and seamlessly move between different experiences without installing separate applications.

The platform combines casual gaming with social features such as profiles, friends, messaging, parties, matchmaking, and player progression.

**Core concept:** One app, many games, shared social experiences.

---

## Core Features

### 1. Game Discovery & Dashboard

- Centralized dashboard displaying all available games.
- Support for both 2D and 3D mobile games.
- Game genres including action, arcade, racing, simulation, puzzles, strategy, and party games.
- Featured, trending, popular, and newly released games.
- Search, categories, and filtering.
- Recently played and favorited games.
- Personalized game recommendations.
- Individual game pages featuring:
  - Game descriptions and screenshots.
  - Number of active players.
  - Multiplayer and single-player information.
  - Game ratings and popularity.
  - Public servers and available lobbies.
  - Friends currently playing.
  - Play and Join buttons.

### 2. Game Launching & Hosting

- Launch games directly inside Rally without installing separate applications.
- Games are dynamically delivered and loaded as needed.
- Seamlessly switch between games and the main dashboard.
- Download and cache game resources to reduce loading times.
- Allow new games and game content updates without requiring full application updates, subject to mobile platform policies.
- Full-screen gameplay with mobile touch controls.
- Shared player identity, authentication, and progression.
- Support for different game engines through a unified game integration system.

### 3. Multiplayer Servers & Lobbies

Similar to Roblox, games can have multiple active servers or instances that players can join.

- Each multiplayer game can host multiple independent servers.
- Users can browse available public servers.
- Display player counts and maximum server capacity.
- Join a random available server using a quick-play button.
- Join specific servers from a server browser.
- Join a friend's server directly.
- Create private or invite-only servers.
- Invite friends to existing servers.
- Automatically create new servers when additional capacity is needed.
- Matchmaking based on game-specific rules.
- Support different lobby sizes depending on the game.
- Allow players to leave a server and return to the Rally dashboard.
- Handle player disconnections and reconnections.

#### Server Types

- **Public Servers:** Open sessions that anyone can join.
- **Private Servers:** Restricted sessions accessible through invitations or permissions.
- **Party Servers:** Sessions created for groups of friends.
- **Matchmaking Servers:** Automatically assigned sessions based on game-specific matchmaking rules.

### 4. Accounts & User Profiles

- Register and sign in using email or supported authentication providers.
- Custom usernames and profile avatars.
- User bios and customizable profiles.
- Display online status and current game activity.
- View recently played and favorite games.
- Track achievements, statistics, and playtime.
- View friends and mutual connections.
- Account privacy settings.
- Optional integration with Discord and other social platforms.

### 5. Friends & Social System

- Send, receive, and accept friend requests.
- Search for users by username.
- View online, offline, away, and in-game presence.
- See which games friends are currently playing.
- Direct messaging and group conversations.
- Send and receive game invitations.
- Join friends directly in their active game sessions.
- Create parties and move between games together.
- In-app notifications for messages, invitations, and requests.
- Block, mute, and report users.
- Privacy and parental safety controls.

### 6. Party System

Players can form parties before entering games.

- Create and manage parties.
- Invite friends into a party.
- Party leader controls.
- Display party members and their statuses.
- Launch supported games together as a group.
- Automatically place party members in the same server when capacity permits.
- Maintain parties when transitioning between games.
- Leave or disband parties.
- Support party-based matchmaking.

### 7. Game Progression & Achievements

- Persistent game progress.
- Game-specific statistics and player records.
- Achievements and unlockable rewards.
- Global and game-specific leaderboards.
- Friends-only leaderboards.
- High scores and personal bests.
- Multiplayer win/loss statistics.
- Optional platform-wide leveling and experience system.
- Cross-device synchronization of progression.

### 8. Unified Game System

Every game operates within the Rally ecosystem and communicates with shared platform services.

- Unified authentication and player identities.
- Shared friends and social features.
- Standardized game launching and exiting.
- Game server discovery and joining.
- Matchmaking and lobby management.
- Player invitations and party integration.
- Achievement and leaderboard integration.
- Persistent data storage.
- Game-specific save data.
- Secure communication between games and Rally services.
- Common SDK for game developers.

### 9. Mobile Experience

Rally is designed primarily for smartphones and tablets.

- Native applications for iOS and Android.
- Touch-friendly navigation and controls.
- Responsive interfaces for different screen sizes.
- Portrait and landscape orientation support.
- Full-screen game experiences.
- Smooth transitions between the dashboard and games.
- Push notifications for messages, friend requests, and invitations.
- Optimized loading, memory usage, and battery consumption.
- Background and foreground lifecycle handling.
- Cross-platform multiplayer between iOS and Android users.

### 10. Notifications & Activity

- Friend request notifications.
- Game invitations.
- Party invitations.
- Direct message notifications.
- Friends coming online.
- Friends starting games.
- Achievement unlocks.
- Game updates and new releases.
- Customizable notification preferences.

## Initial MVP

The first version of Rally should prioritize the core gaming and multiplayer experience.

1. **Mobile Application:** Functional iOS and Android applications with a polished game dashboard.
2. **Authentication:** User registration, login, and profiles.
3. **Game Library:** A small collection of playable 2D and 3D mini-games.
4. **Dynamic Game Loading:** Launch and exit games without separate installations.
5. **Public Servers:** Players can join available multiplayer game servers.
6. **Private Lobbies:** Players can create private sessions and invite friends.
7. **Friends System:** Add friends, view their online status, and join their games.
8. **Party System:** Group with friends and enter supported games together.
9. **Persistent Progress:** Save scores, player statistics, and game progression.
10. **Cross-Platform Multiplayer:** Android and iOS players can participate in the same game sessions.

## Product Vision

Rally aims to become a mobile-first social gaming destination where users can quickly discover games, connect with friends, and join shared experiences.

Instead of downloading numerous individual games, users install Rally once and gain access to an expanding library of lightweight experiences.

Like Roblox, each game can have its own community, active servers, multiplayer lobbies, and progression systems, while sharing a centralized social network.

The initial focus is a curated selection of high-quality casual games, with the potential to expand into a broader developer and creator ecosystem.

**Rally — One app. Endless games. Better together.**
